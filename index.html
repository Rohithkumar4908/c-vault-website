A password manager written in C

The Secure Password Vault is a C program that keeps your passwords safe behind one master password. It stores them in a scrambled file, checks password strength, generates strong random passwords and locks itself after 3 wrong master-password tries.

This whole website is being served to you by a C program, the same language the vault itself is written in.
