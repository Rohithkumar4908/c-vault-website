What the vault does

  • One master password protects the whole vault
  • Add, view, search and delete saved passwords
  • File is scrambled before saving, so it cannot be read as plain text
  • Password strength checker with reused and common-password warnings
  • Random strong-password generator
  • Locks after 3 wrong master-password tries and logs failed attempts
  • Auto-hides passwords on screen until you ask to see them

Why it matters

Reusing one weak password everywhere is how accounts get taken over. The vault makes it easy to keep a different strong password for every account.
